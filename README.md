#  Student Performance Predictor

##  Overview

The Student Performance Predictor is a machine learning project that estimates a student's academic performance based on daily study habits. It uses a Linear Regression model to predict marks based on study hours, attendance, and sleep patterns.

This project aims to help students understand how their daily routines impact their academic results and provides suggestions for improvement.

---

##  Features

* Predicts student marks based on:

  * Study hours per day
  * Attendance percentage
  * Sleep hours
* Provides personalized suggestions for improvement
* Simple and easy-to-use command-line interface
* Lightweight and beginner-friendly implementation

---

##  Machine Learning Model

* Algorithm: Linear Regression
* Library Used: scikit-learn
* Type: Supervised Learning (Regression)

---

##  Technologies Used

* pandas
* scikit-learn

##  Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/student-performance-predictor.git
```

2. Navigate to the project folder:

```
cd student-performance-predictor
```

3. Install required libraries:

```
pip install pandas scikit-learn
```

---

##  How to Run

Run the Python script:

```
python student_predictor.py
```

Enter the required inputs:

* Study hours per day
* Attendance percentage
* Sleep hours

The program will output:

* Predicted score
* Suggestions for improvement

---

##  Example

**Input:**

```
Study hours: 4  
Attendance: 70  
Sleep: 6  
```

**Output:**

```
Predicted Score: 56.8%

Advice:
- Increase study hours
- Improve attendance
- Get enough sleep
```
